# Restoro - Online Food Ordering System 🍔

Architected and developed a robust food ordering system within a collaborative team environment. Applied the full Software Development Life Cycle (SDLC), SOLID principles, and multiple design patterns to ensure clean, maintainable, and scalable code. Integrated JUnit testing for reliability and quality assurance.

## Features ✅

* **End-to-End Ordering Flow** – Browse, select, order, and track food seamlessly
* **User & Admin Roles** – Role-based access and secure operations
* **Modular Architecture** – Clean code, easy to extend and maintain
* **Design Patterns** – Applied proven patterns to improve flexibility and structure
* **JUnit Testing** – Ensures correctness and stability
* **Responsive UI** – Optimized for desktop and mobile

## How It Works ⚙️

1. Users browse menus, select items, and place orders
2. Admins manage menus, orders, and users
3. System handles secure payments and order tracking

## Technologies Used 🛠️

* **Java** – Core application logic
* **JUnit** – Unit testing
* **MySQL** – Database
* **JFrame** – GUI
* **SOLID & Design Patterns** – Architectural best practices
